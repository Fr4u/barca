# Oficjalne zdjęcia zawodników FC Barcelony

27 portretów i 27 miniatur pobranych 30.09.2026 z [oficjalnej kadry klubu](https://www.fcbarcelona.com/en/football/first-team/players).

Każdy plik jest kopią odpowiedzi oficjalnego serwisu zdjęciowego FC Barcelona: portrety 940×940, miniatury 160×160. Pliki zachowują format zwrócony przez serwis, również gdy różni się on od rozszerzenia adresu źródłowego.

`sources.json` zawiera przypisanie do identyfikatorów zawodników, oficjalne nazwiska, strony profili, adresy pobrania, wymiary i sumy SHA-256. Wpisy używane przez aplikację są w `js/photos.js`.

Źródło zdjęć: FC Barcelona. Zdjęcia nie są oznaczone jako materiały na wolnej licencji; prawa do nich pozostają przy uprawnionych podmiotach.
